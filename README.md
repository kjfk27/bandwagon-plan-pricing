## 买最便宜套餐之前，这几件事值得先知道

**机房可以免费切换。** 官网订购页写明：VPS 可以在机房之间随时免费迁移，数据不丢。这意味着买 CN2 GIA-E 之后发现大阪软银更适合自己，直接在 KiwiVM 面板里切过去就行，不用退了重买。这是搬瓦工相对同类商家一个很实际的优势。

**退款有严格条件。** 官网提供 30 天退款保障，但只针对新注册账户，而且要同时满足几个条件：账户创建不超过 30 天、当月流量用量未超过配额的 10%、账户下 VPS 少于 3 台、累计支付少于 100 美元且支付次数少于 10 次。另外退款是整账号操作——账号下所有 VPS 会一并退款删除，不能只退某一台。想试水的话，先注册账号再下单，别拖着旧账号买。

**1GB 内存能干什么、不能干什么。** 20GB SSD、1GB 内存的配置跑 Nginx 加静态站、轻量数据库、个人代理服务没问题；想跑 Docker 多容器、大型数据库或者吃内存的应用就别想了。内存不够时在 KiwiVM 面板里加 Swap 能续一点命，但治标不治本。预算允许的话，CN2 GIA-E 的 2GB 内存款（$89.99/季）用起来从容得多。

**限量版和常规套餐可以互转。** 老限量版用户可以补差价升级到更新的套餐（比如 $49.99/年限量版升级 THE PLAN），常规套餐之间也支持升降级，这点在配置不够用的时候很省事。

**面板和付款。** 所有套餐都用自家 KiwiVM 面板管理，开关机、重装系统、快照、切换机房都在里面操作，支持支付宝付款，对国内用户来说购买流程没什么门槛。
